# Bundled practice clips

These 19 audio/analysis pairs are the saved development preview catalog. Keep
both `audio/<id>.wav` and `results/<id>.wav.json` in Git. The default Practice
Clip is `05-verified`; the catalog also supplies the recording selector and take
comparisons. The bundle is about 9.6 MB and needs no downloads or analyzer setup.

`/api/dev-performance` reads this bundle when running `npm run dev`. It does not
read ignored evaluation directories. The API and preview remain development-only.

## Provenance

- `05`, `05-verified`: prepared excerpts from URMP's isolated trumpet recording
  `05_Entertainer_tpt_tpt/AuSep_1_tpt_05_Entertainer.wav`.
- `09-triplet`, `09-verified`: prepared excerpts from URMP's isolated trumpet
  recording `09_Jesus_tpt_vn/AuSep_1_tpt_09_Jesus.wav`.
- All other clips are synthetic controls generated by
  `back-end/performance-analyzer/evaluation/prepare.py`.
- Results are saved output from the performance analyzer, copied from
  `back-end/performance-analyzer/evaluation/results/`.

URMP is the University of Rochester Multi-Modal Music Performance dataset.
See the [original project and usage terms](https://labsites.rochester.edu/air/projects/URMP.html).
The pinned source URLs and original download SHA-256 hashes are recorded in
`back-end/rhythm-analyzer/evaluation/acquisition.json`. Excerpt preparation and
timing review are documented alongside that manifest. Bundling these excerpts
does not change the source dataset's usage terms.

## Refreshing a clip

Only maintainers refreshing a saved analysis need to run the evaluation. Copy
the resulting `<id>.wav.json` here from the performance evaluation's `results/`
folder, together with its matching WAV from the performance or rhythm evaluation's
`data/` folder. Preserve audio timing so playback and findings stay synchronized.
Commit both files, then run `npm run test:practice-clips` in `tunity-front-end`.
Do not copy source downloads, temporary files, or private user recordings here.
